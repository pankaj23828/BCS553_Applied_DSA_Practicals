## How to run a practical in VS Code / terminal

1. Open the required assignment folder.
2. Open the required `.java` file.
3. Update the roll number in the first comment line.
4. Open terminal in that folder.
5. Compile and run:

```bash
javac Task1_First_Last.java
java Main
```

Use the actual Java filename in the `javac` command. Each practical is a separate program and contains `class Main`, as required by the lab sheet. Therefore, run one practical at a time and do not compile multiple practical files together in the same folder.

## Folder structure

There is one folder for each of the 15 assignments. Each task has:
- One `.java` source file
- One `_Output.txt` file containing its expected output
